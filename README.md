# Nutrient environments shape amino acid auxotrophy and cross-feeding

This repository contains the data, analysis code, cached model outputs, and figure-generation workflow associated with the manuscript:

**Nutrient environments shape amino acid auxotrophy and cross-feeding**  
Amichai Baichman-Kass, Lianet Noda-García, Jonathan Friedman
  
The analysis examines amino acid auxotrophy and pairwise cross-feeding in *Escherichia coli* and *Bacillus subtilis* across carbon and nitrogen environments. The repository is intended to allow readers to inspect the underlying data processing, reproduce the main analysis tables, and regenerate the manuscript figure panels.

## Main files and folders

### `Consolidated Analysis and Figures.ipynb`

Main analysis notebook. It is organized into four broad sections:

1. **Import data** - loads current-study cross-feeding data, amino-acid requirement data, pathway annotations, and external knockout/fitness datasets.
2. **Generate downstream dataframes** - reconstructs normalized assay tables, filters non-obligate auxotrophs in specific environments, and prepares comparison tables.
3. **Run the random forest model** - loads the cached trained model and cached permutation-importance outputs. The hyperparameter-search and permutation-analysis code is included but commented out to avoid rerunning computationally expensive steps by default.
4. **Generate figures** - creates the manuscript figure panels and supplementary figure panels in `images/`.

### `Data/`

Raw and source datasets used by the notebook.

- `Crossfeeding Experiments/` - plate-reader data for the current-study cross-feeding assays in *B. subtilis* (`Bs`) and *E. coli* (`Ec`), with three experimental repeats per species.
- `AA Requirments Experiments/` - amino-acid requirement measurements used to estimate amino acid requirement per OD unit.
- `AA_synthesis_pathways.csv` - amino acid biosynthesis pathway annotation table used for knockout/pathway analyses.
- `Koo et al Data.xlsx` - external *B. subtilis* knockout dataset used for auxotrophy comparisons.
- `Tong et al Data.xlsx` - external *E. coli* knockout dataset used for auxotrophy comparisons.
- `Wetmore et al Data/` - external pooled-fitness data used for additional *E. coli* auxotrophy comparisons.
- `Sample Names.xlsx` - plate/sample annotation file used to reconstruct sample identities.

### `Generated Tables/`

Intermediate and final processed tables generated by the notebook.

Key files include:

- `big_norm_df.csv` - reconstructed current-study table containing raw means, SEM values, auxotroph monoculture growth, normalized cross-feeding growth, prototroph growth, and related summary columns.
- `filtered_df.csv` - version of `big_norm_df.csv` with environment/species/auxotroph combinations flagged or filtered when auxotrophs grow under a given condition without AA suplementation.
- `Supplemented_AA_data.csv` - long-format table for supplemented amino acid controls and prototroph growth.
- `AA_requirments_dataset.csv` - combined amino-acid requirement dataset.
- `Koo_auxs_df_bs.csv`, `Tong_aux_df_ec.csv`, `Wetmore_aux_df_ec.csv` - processed external auxotrophy summary tables.
- `Random Forest Model/` - cached trained model and cached permutation-importance/model-performance outputs.

### `images/`

Figure panels generated by the notebook will be assigned to this folder. 

## Notes on reproducibility

- Keep the folder names and relative paths unchanged unless you also update the notebook paths.
- The spelling of `AA Requirments Experiments/` and `AA_requirments_dataset.csv` follows the current repository paths and is therefore preserved here.
- Some computationally expensive random forest and permutation-analysis cells are included in the notebook but commented out. Cached outputs are included so that the manuscript figures can be regenerated without rerunning those steps.
- Generated figure panels are written to `images/` using `plt.savefig(...)` calls in the notebook.
